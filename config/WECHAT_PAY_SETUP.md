# 微信支付配置指南

## 配置步骤

### 1. 申请微信支付商户号

访问 [微信支付商户平台](https://pay.weixin.qq.com/) 申请商户号。

### 2. 获取必要参数

申请成功后，你会获得以下参数：
- **商户号 (mchId)**: 微信支付的商户 ID
- **API 密钥 (mchKey)**: 在微信商户平台设置
- **AppID**: 小程序的 AppID（已配置）

### 3. 配置 API 密钥

1. 登录 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 进入「账户中心」→「API 安全」
3. 设置 API 密钥（32位随机字符串）

### 4. 配置支付目录

1. 进入「产品中心」→「开发配置」
2. 添加支付授权目录：`http://你的域名/api/`

### 5. 配置服务器

修改 `server/config/index.js` 中的微信支付配置：

```javascript
wechat: {
  appId: '你的小程序AppID',
  appSecret: '你的小程序AppSecret',
  mchId: '你的商户号',
  mchKey: '你的API密钥',
  notifyUrl: 'https://你的域名/api/payment/wx/notify'
}
```

### 6. 配置 SSL 证书（生产环境必需）

微信支付要求使用 HTTPS。将证书文件放在 `server/certs/` 目录：
- `apiclient_cert.pem` - 证书
- `apiclient_key.pem` - 密钥

### 7. 配置服务器域名

在微信小程序后台：
1. 进入「开发」→「开发管理」→「开发设置」
2. 配置服务器域名（request 合法域名）
3. 添加你的后端 API 域名

### 8. 配置业务域名（可选）

如果需要使用 web-view，需要配置业务域名。

## 测试支付

### 沙箱环境测试

微信支付提供沙箱环境用于测试：

1. 使用沙箱环境的特殊商户号和密钥
2. 调用沙箱环境的 API 地址
3. 使用测试金额（如 1.01 元会触发特定场景）

### 真机测试

1. 使用微信开发者工具的真机调试
2. 或者预览/上传代码后在手机测试
3. 支付金额必须大于 0.01 元

## 常见问题

### 1. "商户号 mch_id 与 appid 不匹配"
- 确保商户号已绑定到小程序 AppID
- 在微信商户平台的「产品中心」→「AppID账号管理」中绑定

### 2. "签名错误"
- 检查 API 密钥是否正确
- 注意密钥区分大小写
- 确保没有多余的空格

### 3. "无法发起支付"
- 检查小程序的 AppID 是否正确
- 检查是否在小程序后台配置了服务器域名
- 检查支付目录是否正确配置

### 4. 回调通知收不到
- 确保服务器可以被外网访问
- 检查 notifyUrl 是否配置正确
- 检查防火墙是否放行 443 端口

## 安全注意事项

1. **不要**将商户密钥提交到代码仓库
2. 使用环境变量存储敏感信息
3. 生产环境必须使用 HTTPS
4. 验证所有支付回调的签名
5. 做好订单幂等性处理
